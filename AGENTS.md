## Architecture rules
- All user data lives in browser IndexedDB (`src/lib/db.ts`); no backend, auth or cloud services — the app must stay free and offline-capable.
- Scoring/date logic is pure in `src/lib/habit-logic.ts` and covered by `src/test/habit-logic.test.ts`; keep UI calculations going through it so numbers agree across pages.
- Service worker is generated by vite-plugin-pwa and registered only from `src/lib/pwa.ts`, which refuses dev/preview hosts.
